 

Đối với hooks trong Claude Code, kết quả đầu ra của script được đọc qua **stdout** để nạp vào context window, nhưng chỉ khi bạn trả về **JSON output** chứ không phải plain text[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output).

Plain stdout được ghi vào debug log, không được thêm vào context của Claude[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output). Để truyền thông tin vào context của Claude, bạn phải:

1. Exit với code 0[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output)
2. Trả về JSON object chứa field `additionalContext`[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output)

Ví dụ với `jq` và `echo`:

```bash
#!/bin/bash
input=$(cat)
context_text="Dependencies installed: node_modules, .venv"
echo "{\"hookSpecificOutput\": {\"hookEventName\": \"Setup\", \"additionalContext\": \"$context_text\"}}" | jq -c
```
[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output)

Bạn **có thể** can thiệp stdout bằng `jq` và `echo` để tạo JSON output[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output). Hook output strings, bao gồm `additionalContext`, bị giới hạn ở 10,000 ký tự[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output).

**Lưu ý quan trọng:** Stdout của bạn chỉ được chứa JSON object. Nếu shell profile của bạn in text khi khởi động, nó có thể làm hỏng việc parse JSON[(1)](https://code.claude.com/docs/en/hooks#hook-input-and-output).
